# MathQuest

Интерактивная игра по математике для **1–12 классов**: темы проходятся не как сухие примеры, а как миссии из жизни и профессий — пекарь, кассир, архитектор, пилот, банкир, врач, логист.

Каждый класс — остров на карте. Внутри — сюжетные задачи с подсказкой, объяснением «где это пригодится», опытом и звёздами. Прогресс хранится в браузере. Языки: русский, қазақша, English.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:5174](http://localhost:5174).

## Стек

Vite + React + TypeScript. Сборка для GitHub Pages кладётся в `docs/`.
